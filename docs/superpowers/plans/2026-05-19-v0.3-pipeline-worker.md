# V0.3 Pipeline Completion + Workerization Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Complete L1/L2/L3 pipeline scheduling, checkpoint recovery, Postgres worker locking, admin reindex, and a separate worker entry point.

**Architecture:** Expand the minimal V0.2 pipeline into a stage-aware scheduler with per-session L1 timers, downward-only L2 timers, and a global serial L3 queue. Use in-process queues for SQLite and DB-backed jobs for Postgres worker mode. Keep worker orchestration outside FastAPI controllers.

**Tech Stack:** asyncio, SQLAlchemy async, FastAPI, pytest, pytest-asyncio, Postgres `FOR UPDATE SKIP LOCKED`.
