# V0.3 流水线补全 + Worker 化执行计划

> **给执行代理：** 必须使用子技能 `superpowers:subagent-driven-development`（推荐）或 `superpowers:executing-plans`，按任务逐项执行。本计划使用 `- [ ]` 复选框跟踪进度。

**目标：** 补全 L1/L2/L3 流水线调度、checkpoint 恢复、Postgres worker 锁、管理端重建索引，以及独立 worker 启动入口。

**架构：** 将 V0.2 的最小流水线扩展为感知阶段的调度器：每个 session 有 L1 计数与 idle 定时器，L2 使用只向下推进的定时器，L3 使用全局串行队列。SQLite 使用进程内队列；Postgres worker 模式使用数据库任务表。worker 编排不放在 FastAPI controller 内。

**技术栈：** asyncio、SQLAlchemy async、FastAPI、pytest、pytest-asyncio、Postgres `FOR UPDATE SKIP LOCKED`。
