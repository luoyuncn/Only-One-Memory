# V0.6 Production Hardening Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Harden Only-One-Memory for production use with auth scopes, audit, import/export/delete-user, metrics, migration tooling, Docker, and operational documentation.

**Architecture:** Add production concerns around the existing `MemoryCore` and store boundaries without moving business logic into HTTP controllers. Auth and audit wrap API calls; export/import/delete operate through domain services; metrics observe core events.

**Tech Stack:** FastAPI dependencies, Pydantic v2, SQLAlchemy async, Prometheus client, Docker, Alembic, pytest.
