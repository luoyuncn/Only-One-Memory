# V0.6 生产化加固执行计划

> **给执行代理：** 必须使用子技能 `superpowers:subagent-driven-development`（推荐）或 `superpowers:executing-plans`，按任务逐项执行。本计划使用 `- [ ]` 复选框跟踪进度。

**目标：** 为 Only-One-Memory 增加生产使用所需能力：认证 scope、审计、导出/导入/删除用户、指标、迁移工具、Docker 与运维文档。

**架构：** 在既有 `MemoryCore` 与 store 边界之外补充生产化能力，不把业务逻辑搬进 HTTP controller。认证与审计包裹 API 调用；导出、导入、删除用户通过领域服务执行；指标观察 core 事件。

**技术栈：** uv、FastAPI dependencies、Pydantic v2、SQLAlchemy async、Prometheus client、Docker、Alembic、pytest。

**项目约束：** 使用 `uv` 管理依赖、锁文件和命令执行；所有测试和工具命令都使用 `uv run ...`。编写代码时，人工注释默认使用中文，只在外部协议字段、第三方 API 名称、固定错误文本或上游英文术语需要精确保留时使用英文。
