# V0.2 L1 + Hybrid Recall Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn captured L0 events into L1 memories and expose hybrid recall/search across SQLite/sqlite-vec and Postgres/pgvector.

**Architecture:** Keep L1 extraction, dedup, memory persistence, and recall as separate domain services behind `MemoryCore`. Prompt modules are first-class files with MIT attribution to TencentDB-Agent-Memory. Store capabilities determine native hybrid, FTS+vector RRF, or degraded search behavior.

**Tech Stack:** Pydantic v2, SQLAlchemy async, FastAPI, pytest, pytest-asyncio, OpenAI-compatible LLM/embedding clients, sqlite-vec, pgvector.
