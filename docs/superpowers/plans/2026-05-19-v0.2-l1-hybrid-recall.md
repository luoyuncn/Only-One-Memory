# V0.2 L1 + 混合召回执行计划

> **给执行代理：** 必须使用子技能 `superpowers:subagent-driven-development`（推荐）或 `superpowers:executing-plans`，按任务逐项执行。本计划使用 `- [ ]` 复选框跟踪进度。

**目标：** 将已捕获的 L0 事件提炼成 L1 记忆，并在 SQLite/sqlite-vec 与 Postgres/pgvector 两种后端上暴露混合召回与记忆搜索能力。

**架构：** L1 抽取、去重、记忆持久化与召回分别作为 `MemoryCore` 背后的领域服务。Prompt 模块作为一等文件存在，并明确标注对 TencentDB-Agent-Memory 的 MIT 归因。存储能力决定使用原生混合检索、FTS + 向量 RRF 融合，或降级检索。

**技术栈：** Pydantic v2、SQLAlchemy async、FastAPI、pytest、pytest-asyncio、OpenAI 兼容 LLM/Embedding 客户端、sqlite-vec、pgvector。
