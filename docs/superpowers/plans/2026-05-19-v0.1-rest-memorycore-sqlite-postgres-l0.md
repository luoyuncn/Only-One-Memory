# V0.1 REST + MemoryCore + SQLite/Postgres L0 执行计划

> **给执行代理：** 必须使用子技能 `superpowers:subagent-driven-development`（推荐）或 `superpowers:executing-plans`，按任务逐项执行。本计划使用 `- [ ]` 复选框跟踪进度。

**目标：** 构建第一版可运行的 REST 服务，支持记录 L0 原始对话事件，并能在 SQLite/sqlite-vec 与 Postgres/pgvector 两种后端上搜索原始对话。

**架构：** FastAPI 只作为 HTTP 适配层，所有业务行为都进入 `MemoryCore`。存储实现统一遵守 `MemoryStore` 能力契约，使捕获和搜索路径可以同时适配 SQLite 与 Postgres。V0.1 只做到 L0 与原始对话搜索，不实现 L1/L2/L3。

**技术栈：** Python 3.11+、FastAPI、Pydantic v2、SQLAlchemy async、aiosqlite、asyncpg、Alembic、sqlite-vec、pytest、pytest-asyncio、httpx。

from only_one_memory.memory_core.config import StoreConfig

async def test_sqlite_l0_upsert_and_fts_search(tmp_path):
