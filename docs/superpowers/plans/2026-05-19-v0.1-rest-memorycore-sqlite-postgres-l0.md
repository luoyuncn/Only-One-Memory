# V0.1 REST + MemoryCore + SQLite/Postgres L0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the first runnable REST service that records L0 conversation events and searches raw conversations on both SQLite/sqlite-vec and Postgres/pgvector.

**Architecture:** FastAPI is only the adapter; all behavior enters `MemoryCore`. Store implementations conform to `MemoryStore` capabilities so the same capture/search path works across SQLite and Postgres. V0.1 intentionally stops at L0 and raw conversation search.

**Tech Stack:** Python 3.11+, FastAPI, Pydantic v2, SQLAlchemy async, aiosqlite, asyncpg, Alembic, sqlite-vec, pytest, pytest-asyncio, httpx.
