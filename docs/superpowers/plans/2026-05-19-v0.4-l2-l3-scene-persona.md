# V0.4 L2/L3 场景 + 人设执行计划

> **给执行代理：** 必须使用子技能 `superpowers:subagent-driven-development`（推荐）或 `superpowers:executing-plans`，按任务逐项执行。本计划使用 `- [ ]` 复选框跟踪进度。

**目标：** 将 L1 记忆转换为 L2 场景块与 L3 人设画像，尽可能还原 TencentDB-Agent-Memory 的 prompt 行为，并通过受控工具运行器保证安全。

**架构：** 场景与人设生成是由 prompt 模块和沙箱工具运行器驱动的领域服务。L2/L3 数据通过 `MemoryStore` 存储，同时保留 Markdown 可读性。工程代码负责索引、导航、归因与安全检查。

**技术栈：** Pydantic v2、FastAPI、SQLAlchemy async、pytest、OpenAI 兼容 LLM runner、Markdown front matter 解析。
