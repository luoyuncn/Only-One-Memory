# V0.4 L2/L3 Scene + Persona Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Convert L1 memories into L2 scene blocks and L3 persona profiles with high-fidelity TencentDB-Agent-Memory prompt behavior and controlled tool runners.

**Architecture:** Scene and persona generation are domain services driven by prompt modules and sandboxed tool runners. L2/L3 data is stored through `MemoryStore` while retaining Markdown readability. Engineering code owns indexing, navigation, attribution, and safety checks.

**Tech Stack:** Pydantic v2, FastAPI, SQLAlchemy async, pytest, OpenAI-compatible LLM runner, Markdown front matter parsing.
