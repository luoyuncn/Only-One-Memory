# V0.5 Context Offload Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add short-term symbolic memory: refs, offload entries, Mermaid graphs, restore, and message compression helpers.

**Architecture:** Offload is separate from L0/L1/L2/L3 but connected through `tool_result_ref` and restore APIs. Raw tool outputs are stored as refs; entries summarize tool pairs; Mermaid graphs provide compact task state; restore allows deterministic drill-down.

**Tech Stack:** FastAPI, Pydantic v2, SQLAlchemy async, pytest, OpenAI-compatible LLM runner, Mermaid text generation.
