# V0.5 上下文 Offload 执行计划

> **给执行代理：** 必须使用子技能 `superpowers:subagent-driven-development`（推荐）或 `superpowers:executing-plans`，按任务逐项执行。本计划使用 `- [ ]` 复选框跟踪进度。

**目标：** 增加短期符号记忆能力：refs、offload entries、Mermaid 图、restore，以及消息压缩辅助函数。

**架构：** Offload 独立于 L0/L1/L2/L3，但通过 `tool_result_ref` 与 restore API 连接。原始工具输出存储为 refs；entries 总结工具调用与工具结果；Mermaid 图提供紧凑的任务状态；restore 支持确定性下钻恢复。

**技术栈：** FastAPI、Pydantic v2、SQLAlchemy async、pytest、OpenAI 兼容 LLM runner、Mermaid 文本生成。

from httpx import ASGITransport, AsyncClient

from only_one_memory.app.main import create_app


async def test_offload_entry_graph_restore_round_trip(tmp_path, monkeypatch):
    monkeypatch.setenv("ONLY_ONE_MEMORY_DATA_DIR", str(tmp_path))
    app = create_app()
    async with AsyncClient(transport=ASGITransport(app=app), base_url="http://test") as client:

        await client.post("/v1/offload/entries", json={"tenant_id": "default", "session_id": "s1", "tool_call_id": "call1", "tool_name": "read_file", "summary": "读取文件", "score": 8, "node_id": "N1", "result_ref": ref.json()["id"]})
        graph = await client.get("/v1/offload/graph/s1")
        restored = await client.post("/v1/offload/restore", json={"tenant_id": "default", "session_id": "s1", "node_id": "N1"})

    assert "N1" in graph.json()["mermaid"]
